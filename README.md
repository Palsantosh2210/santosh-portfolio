# Santosh Pal: Portfolio (React + Vite)

1. Edit `src/data.js` (your links, projects, client work). Nothing else needs changing.
2. Run locally: `npm install` then `npm run dev`
3. Build: `npm run build` (output goes to `dist/`)
4. Deploy free: push to GitHub, then import the repo on vercel.com or netlify.com
   (build command `npm run build`, output folder `dist`).

## Live API endpoint
`api/profile.js` is a free serverless function. On Vercel it is live at `https://YOUR-SITE.vercel.app/developer/santosh-pal` (vercel.json maps that path to the function).
It also works locally while `npm run dev` is running: http://localhost:5173/developer/santosh-pal
(Netlify / GitHub Pages do not run the api/ folder; use Vercel for this feature.)
